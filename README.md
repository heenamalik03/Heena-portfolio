# Heena Malik | Portfolio

An interactive portfolio website designed like a magazine cover, for Miss Rohtak 2K25, fashion designer and content creator.

## What I designed
- The concept: a magazine-cover homepage where the headings work as the menu
- The content and structure: a "Pick a side of me" section and an "Ask me anything" section for interviewers
- The black, white and soft rose color mood, chosen for strong contrast
- The contact section with call, email, LinkedIn and Instagram

## Features
- Tabs to switch between Creator, Performer, Scientist and Teacher
- Expandable question-and-answer section
- Tap-to-call phone number and copy buttons for email and phone
- Responsive layout for mobile and desktop
- Automatic light and dark mode
- Keyboard-friendly navigation

## Built with
- HTML, CSS and vanilla JavaScript in a single file
- Google Fonts (Abril Fatface and Karla)
- Built with the help of Claude (Anthropic), under my design direction
- Hosted on GitHub Pages
